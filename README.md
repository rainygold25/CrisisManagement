🌍 Crisis Management App

Authors: Ranya Rajesh Prasad, Shipra Jha
Affiliation: Stevenson High School – Science REACH Program
Project Type: Design Project


📌 Project Overview

Every year, 218 million people are affected by natural disasters globally. Many lives are lost not only during disasters, but in the aftermath, 
when families lack access to fresh food, clothing, shelter, and medical resources. Traditional emergency systems like 911 often face delays or infrastructure gaps,
particularly in developing regions
.
The Crisis Management App bridges this gap by connecting resource providers with resource seekers in real time. It leverages AI, APIs, and mobile technology to 
help users obtain essential resources and send emergency alerts instantly.


🚀 Features

Emergency SOS – One-click button sends SMS with current location to all designated emergency contacts.

Resource Posting – Volunteers and donors upload available resources (food, clothing, shelter, personal care, etc.).

AI-based Classification – Transfer Learning auto-categorizes uploaded resources into 7 categories with ~90% accuracy.

Resource Search – Filter by keyword, category, and distance to quickly find needed resources.

Resource Update – Donors can edit or update available quantities, synced via Firebase.

Smooth Navigation – Designed with simplicity in mind; access any feature in 3 clicks or fewer.


🔧 Technical Design

APIs Used: Contacts, Location Services, SMS, Camera, Google Maps

Backend: Firebase Database for real-time sharing of resource data

AI Model: Transfer Learning-based image classifier for auto-labeling resources

Platform: Android Studio (prototype built on Google Pixel device)


📊 Testing & Results

AI Model Accuracy: ~89.5% after fine-tuning epochs

User Testing (50+ responses):

Consistency: 81% → 89%

Search Ease: 77% → 87%

Design Simplicity: 77% → 85%

Navigation Usefulness: 81% → 89%

Prototype testing confirmed significant reduction in time to locate critical resources, directly improving survival chances.


📱 Future Enhancements

Voice-enabled speech-to-text entry for faster resource uploads

AI-based personalized search recommendations

Improved image orientation and cross-platform stability

Customization for different types of crises (wildfires, hurricanes, earthquakes)


📖 Impact

The Crisis Management App is designed to save lives by:

Reducing delays in accessing emergency help

Connecting disadvantaged communities with nearby resource providers

Delivering critical resources in minutes, not days

By connecting communities through AI and mobile tools, this project demonstrates how technology can make the world more resilient and prepared for crises.
